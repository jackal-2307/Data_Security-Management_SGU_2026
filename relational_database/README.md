# Relational Data Modeling Assignment

The folder contains the coursework materials and the completed ER-to-relational design work for the `Week 3+` worksheet.

## Project structure

- `Week 3+.pdf` — original assignment sheet.
- `ERD_to_RDM_Solutions.md` — conceptual mapping notes for Bài 1 to Bài 4.
- `SQL/` — SQL Server T-SQL implementation scripts for each exercise.
- `Documentation/Final_Report.md` — academic-style report summarizing the design decisions.
- `Diagrams/Bai_3_Ship_Movement_ERD.mmd` — Mermaid ERD for the ship-movement problem.

## Included SQL scripts

- `SQL/01_Bai_1_BenhVien.sql`
- `SQL/02_Bai_2_CongTyThietBi.sql`
- `SQL/03_Bai_3_ShipMovement.sql`
- `SQL/04_Bai_4_NganHang.sql`

## Execution note

These scripts are written for Microsoft SQL Server / T-SQL and are intended for use in SSMS or VS Code with the MSSQL extension. No SQL Server service is installed in this environment, so they have not been executed here.

Before running them in a real database, check the target database and adjust the object names and constraints to match your actual environment.
