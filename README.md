## SQL environment

SQL scripts use Microsoft SQL Server and T-SQL. Open a script in SQL Server Management Studio (SSMS), connect to the appropriate database, and execute it there. The nested-query solutions expect a COMPANY-style schema; create or select a database with matching tables and columns before running them.

Review each script before execution, especially scripts that create or modify database objects.
